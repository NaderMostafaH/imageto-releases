# ImageTo — Downloads

**[⬇️ Download the latest installer](https://github.com/NaderMostafaH/imageto-releases/releases/latest)**

Each release contains `ImageTo-Setup-<version>.exe` for Windows. Once
installed, ImageTo keeps itself up to date automatically from this page.

This repository hosts only the installers and the auto-update feed
(`latest.yml`). The application source code is maintained separately.
